Design a highly detailed futuristic cyber Y2K anime dashboard interface inspired by visual novel UI, game HUD systems, sci-fi dossiers, and old webcore aesthetics.

Use a dark monochrome grayscale color palette with metallic textures, sharp rectangular panels, layered borders, diagonal cuts, barcode decorations, scanline overlays, grid-based modular layouts, techno typography, and dense information composition.

The interface should feel like a character database system or futuristic profile terminal rather than a modern website.

Style references:
- cyber Y2K
- anime dashboard UI
- visual novel interface
- techwear UI
- sci-fi control panel
- holographic dossier system
- Nier Automata UI
- Persona 5 menu design
- Serial Experiments Lain web aesthetic
- futuristic HUD overlays

Layout structure:
- top navigation tabs
- profile/avatar information card
- about section
- social/media link sidebar
- large showcase image panel
- status/commission/system info section
- footer with barcode and techno decorations

Design rules:
- avoid minimalism
- avoid soft rounded modern UI
- use hard edges and clipped corners
- extremely layered panel composition
- compact information density
- decorative separators and symbols everywhere
- subtle glow and noise texture
- grayscale anime illustrations with high contrast
- thin white borders with inset shadows
- CSS-grid inspired alignment
- interface should look immersive, cinematic, tactical, and futuristic

Typography:
Use futuristic techno fonts similar to Orbitron, Rajdhani, Eurostile, Michroma, or Bank Gothic.

Visual effects:
- grain/noise overlay
- scanlines
- bloom highlights
- contrast-heavy monochrome rendering
- subtle glass + metallic surfaces
- holographic panel feeling

Overall mood:
dark, stylish, tactical, futuristic, elegant, mysterious, anime cybercore, digital dossier aesthetic.
